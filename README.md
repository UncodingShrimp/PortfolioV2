# Mon portfolio -> [elie-dev.fr](https://elie-dev.fr)

Portfolio personnel d'Elie Saidane Lemercier, réalisé avec React et Vite. Le site présente des projets, des compétences et des moyens de contact.

## Technologies

- React 18
- Vite 7
- Tailwind CSS
- Express 5 pour servir la version de production

## Prérequis

- Node.js `20.19+`
- npm

## Installation

```bash
git clone https://github.com/UncodingShrimp/PortfolioV2.git
cd PortfolioV2
npm install
```

**Créez le fichier de configuration local à partir de l'exemple :**

```bash
cp .env.example .env
```

## Développement

```bash
npm run dev
```

Vite démarre le serveur de développement sur le port `3000`.

## Build et aperçu de production

**Créer les fichiers de production dans `dist/` :**

```bash
npm run build
```

Un aperçu local du build avec Vite est également disponible via `npm run preview`.

## Contenu

Les composants de l'interface se trouvent dans `src/components/`, et les images du portfolio dans `public/`.
